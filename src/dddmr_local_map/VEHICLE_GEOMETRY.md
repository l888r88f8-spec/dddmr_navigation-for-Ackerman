## 当前权威几何（2026-11-05 用户最新指令）

当前 `/home/robot/hunterse_ws` 中的 Hunter SE 驱动是几何权威来源：
`hunter_ros2/hunter_base/include/hunter_base/hunter_params.hpp` 的
`HunterSEParams`。导航参数必须与驱动一致，不得再用旧的 `0.460 / 0.550`
标定反推并改写驱动。

- 轴距（前后轴）：`L = 0.550 m`
- 前/后轮距：`t = 0.520 m`
- 前轮**内侧**机械最大转角：`22 deg = 0.3839724354387525 rad`
- 等效虚拟中央最大转角：
  `delta_c = atan(L / (L/tan(22 deg) + t/2)) = 0.3270520925102273 rad`
  （18.73870458 deg）
- 驱动最大线速度：`4.8 m/s`。该值只属于驱动能力，不授权修改导航的
  `vx_max=1.0 / wz_max=0.526` 及其加速度限制。

理想阿克曼后轴中心最小转弯半径：

```text
R = L/tan(inner) + t/2
  = 0.550/tan(0.3839724354387525) + 0.520/2
  = 1.621297769378963 m
```

历史记录中的 `0.460 m` 轴距、`0.550 m` 轮距、`0.314615456384891 rad`
中央角（`R = 1.4135 m`）以及手动 `1.31 m / 1.9 m` 最小半径参考，均已被
2026-11-05 用户指令取代，不再作为当前实车参数。`1.31 m` 的参考系也从未
确认（后轴中心、车身外缘或其他点），不得用于当前标定。

## 转向几何（2026-11-05 用户确认）

采用 ROS `base_link`（x 向前、y 向左）和理想阿克曼假设：转向中心在后轴
线上，内侧前轮路径半径比后轴中心半径小 `track/2`。

- `inner = 22 deg = 0.3839724354387525 rad`
- `R = 0.550/tan(22 deg) + 0.520/2 = 1.621297769378963 m`
- `delta_c = atan(0.550/1.621297769378963)
           = 0.3270520925102273 rad = 18.73870458 deg`

运动模型仍为既有 `wz = v*tan(delta)/L`，没有新增运动模型架构。导航
全局/局部/轨迹生成器默认值和两套 YAML 均使用该中央角；驱动侧仍以
22 deg 内轮角命令并在 CAN/机械限位处饱和。仍需实车在标记场地复核前后轮
转角、轮胎滑移和实际轨迹半径。
